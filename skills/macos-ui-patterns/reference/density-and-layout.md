# Density and layout

## 1. Density is a feature, not a failing

The Mac has room and the user expects it used. Unlike mobile, you can and should lay out content in two axes at once, run multiple columns, and keep more on screen.

- Don't port iOS's "one screen, one job / one axis" restraint wholesale — it reads as a stretched iPhone app.
- Don't port iOS padding wholesale either; Mac spacing is tighter (base font ~13pt vs ~17pt on iOS). Generous iOS padding looks bloated on a Mac.
- **Check:** does the window feel sparse or oversized? On the Mac, that's usually under-using the space, not calm design.
