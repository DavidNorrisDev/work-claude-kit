# Native controls and forms

## 9. Native controls and forms

Use Mac control idioms rather than iOS ones.

- `Form` with `.formStyle(.grouped)` and `LabeledContent` for settings and structured input.
- Popup buttons, segmented controls, steppers, and `.controlSize(...)` where a compact control fits better than a chunky iOS one.
- Pick the control the Mac user expects, not the touch-sized equivalent.
- **Check:** are these macOS controls at appropriate control sizes, or oversized iOS controls dropped in?
