# Windows, scenes, and appearance

## 8. Windows and scenes

- Windows are resizable. Set sensible minimum (and where relevant ideal) sizes so the layout never collapses; let it breathe when enlarged.
- Provide a `Settings` scene for preferences (the standard ⌘, window) rather than an in-content settings page. A keyboard-shortcut cheat sheet fits naturally here.
- Don't fight the window chrome — respect the traffic lights and toolbar region.
- Support multiple windows where the app benefits (e.g. comparing two reports side by side).
- **Check:** does the layout survive being resized small and large, and is there a proper Settings (⌘,) scene?

## 11. Light and dark

Respect the system appearance; design both, and don't invert one to make the other. Mac dark mode in particular needs its own treatment. The detail lives in `visual-design-fundamentals`; the macOS-specific point is simply that both appearances are first-class and a direct inversion looks wrong.
