# Overlays

Text over imagery needs help to stay legible.

- Use a linear gradient that fades from the image into a readable backing, not a flat scrim that flattens the image. A progressive blur over the gradient reads more modern where you can manage it.
- SwiftUI: a `LinearGradient` overlay, optionally over a thin Material.
- **Check:** is text over an image backed by a gradient that preserves the image, rather than a flat dark layer?
