# Quick audit checklist

1. **Signifiers** — selected/active/disabled/tappable readable without labels.
2. **Hierarchy** — a clear focal point; contrast in size, weight, colour.
3. **Spacing** — 4-point scale; grouping by whitespace, not nesting.
4. **Type** — one face, constrained sizes, display text tightened, Dynamic Type intact.
5. **Colour** — one accent + neutral ramp; 60/30/10; semantic colour meaningful; contrast passes.
6. **Dark mode** — its own palette; depth via elevation, not shadow.
7. **Shadows** — subtle; felt not seen; Materials where they fit.
8. **States** — every control has its full state set; every action responds.
9. **Overlays** — gradient-backed text over imagery.
