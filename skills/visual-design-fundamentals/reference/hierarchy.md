# Visual hierarchy

Hierarchy comes from contrast — the difference between big and small, accent and neutral, top and bottom. Without it, a card reads like a spreadsheet.

- Most important element: larger, heavier, nearer the top. Secondary detail: smaller, below.
- Use position and an accent colour to pull the eye to one thing (a right-aligned, accent-coloured value reads as primary).
- Imagery makes a layout scannable; lead with it where the content supports it.
- **Check:** is there a clear first thing the eye lands on, or does everything compete equally?
