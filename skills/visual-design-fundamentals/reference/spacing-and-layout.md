# Spacing and rhythm

Whitespace is the primary grouping tool: things close together read as related (proximity), so group with spacing before reaching for containers.

- Use a 4-point spacing system — every gap a multiple of 4 — so spacing is consistent and always halvable. Define spacing tokens rather than scattering magic numbers.
- Grids are guidelines, not law; lean on whitespace over rigid columns.
- **Check:** are gaps from a consistent 4-point scale, and does grouping come from space rather than nested boxes?
